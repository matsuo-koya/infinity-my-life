# INFINITY MY LIFE — 半速のバロック

1787年の賽と、1965年のテープを混ぜる自動生成機。

2つの賽を転がすと、小節ごとに「1787年の和音」「1965年の和音」「そのあいだ」の
どれを採るかが決まる。十六回振ると16小節の骨ができ、そこから変奏曲集が組まれる。
1965年へ寄った変奏は、**いったん半分の速さで書き出してから倍速で戻して**鳴らす。

音はすべてブラウザ内で合成・再生される。サーバーは要らない。

## なぜこの二つが混ざるのか

**1787年の側。** モーツァルト（と署名された誰か）の《音楽のさいころ遊び》K.516f は、
どの目が出ても音楽になるように、小節位置ごとの和声上の役目が固定してある。
176枚の札を全部測ると16か所中13か所で11の候補が同じ和音を指す
（[dice-the-mozart](https://github.com/matsuo-koya/dice-the-mozart) で実測した）。
イ長調に移すと、その骨はこうなる。

```
A  A  E  A | B7 E  B7 E7 | B7 E  A  E | A  A  E7 A
```

**1965年の側。** 10月22日、ロンドンのEMIスタジオ。レノンに「バロックっぽいものを」と
頼まれたジョージ・マーティンは、バッハ風のソロを書いたが曲の速さでは弾けなかった。
そこでテープを半分の速さで回し、1オクターヴ下をゆっくり弾いて、戻したときに倍速にした。
その進行は、同じイ長調でこう動く。借用した短調のIV（Dm→A）がよく効く。

```
A  E  F♯m A7 | D  Dm A  A |（8小節を2度）
```

**混ざる理由は単純で、どちらも様式模倣だからだ。** マーティンが真似ていたのはバッハで、
モーツァルトの図形変奏がやっているのも同じこと。しかも二人とも、自由にしてよい場所と
してはいけない場所を先に分けてから、中身をあとで流し込んでいる。

もう一つ。**どちらも「人がぎりぎり弾いていない」音がする。**
賽が並べた音符と、半速で弾いて倍速に戻した演奏は、間合いが平らになるという点で似る。

## 賽はダイヤルを回している

小節ごとに、1787年の和音・つなぎの和音・1965年の和音を並べておく。
賽の和 2 が左端、12 が右端。つまり賽は二択を引いているのではなく、
**178年ぶんの距離のどこを取るか**を決めている。

| 賽の和 | 2–4 | 5–9 | 10–12 |
| --- | --- | --- | --- |
| 出る和音 | 1787年 | あいだ | 1965年 |
| 確率 | 16.7% | **66.7%** | 16.7% |

2つの賽は7がいちばん出やすいので、**この機械はまん中に寄る**。
混ぜようとして混ぜているのではなく、賽という物のかたちが勝手にまん中を選ばせている。

和声の道順は **1,594,323 通り**。16小節のうち3か所は、そもそも両者が一致している。

## できること

- **賽を振る** — 1回ずつでも、十六回いっぺんでも
- **ダイヤル表** — 16小節×3段。引いた枡が灯る。上が1787年、下が1965年
- **変奏曲集** — 主題／走句／続進／左手へ／**トリルと走り下り**／同主短調／終曲（コーダつき）。
  どの変奏をどちらの語彙で書くか、どこでテープを回すかも、同じ16個の出目が決める
- **半速録音** — 1965年へ寄った変奏は、OfflineAudioContext で半分の速さ・1オクターヴ下に
  書き出してから、再生速度2.0で戻す。テープでやられたのと同じ演算
- **音** — フォルテピアノ／自鳴琴（いずれも合成）／サンプラー（Salamander、選んだときだけ読む）
- **音律と残響** — 平均律・キルンベルガーIII・ヴァロッティ・中全音律／小部屋・広間・聖堂
- **鍵盤** — FF–f³ の61鍵。当時の白黒（幹音が黒）にも切り替わる
- **上演と録画** — 賽から終曲まで通しで走らせ、1280×720 の画と音を **MP4** に書き出す
- **番地** — 16個の出目そのものが番地。URL の `#` に入る。乱数はほかに使っていないので、
  同じ番地なら一巡ぶんが一音まで同じ

## 第4変奏について

マーティンのソロは、同じ音型を延々と繰り返してはいない。トリルが所々に混じり、
走り下り（ランダウン）と組み合わさって、1曲のあいだ耳が飽きないようにできている。
第4変奏はその方向で、小節ごとに身ぶりを取り替える。

1. 走り下り — 高いところから音階で駆け下りる
2. トリル — 長い音にかけ、あとを走句で埋める
3. 上行と保続 — 分散和音で登って、頂点で伸ばす
4. プラルトリラーと走句 — 頭に短いぎざぎざ、そのあと走る

終止の小節（第8・第16）では必ずトリルにする。古典派の作法でもある。

## 動かす

```bash
npm install
npm run dev
```

`npm run check` で検算（両端が1787年／1965年の進行を正しく再現するか、
どの目でもどの楽章でも拍が埋まるか、音が鍵盤に収まるか。のべ22万音を確かめる）。

`npm run build` で `dist/` に出る。GitHub Pages へは `main` への push で自動デプロイ。

## 権利について

**和音進行そのものに著作権はない。** ここには旋律も、1965年の実際のソロも、一音も入っていない。
借りたのは「Aから始まってEへ行き、F♯mを経て、借りた短調のIVでAへ帰る」という道順と、
テープを半分の速さで回すという手順だけ。鳴っている音はすべてこの機械が新しく作ったもの。

| もの | 権利 | 出所 |
| --- | --- | --- |
| 1787年の骨 | パブリックドメイン | W. A. モーツァルト作とされる K.516f（帰属は疑わしい）。作曲者1791年没 |
| 1965年の進行と手法 | 著作権の対象外 | 和音進行と録音手順。旋律・録音・採譜は一切使っていない |
| 同梱のピアノ標本<br>`public/salamander/*.mp3` | **CC BY 3.0** | Salamander Grand Piano V3、録音・制作 [Alexander Holm](https://archive.org/details/SalamanderGrandPianoV3) 氏。[Tone.js](https://tonejs.github.io/) 配布の変換版 |
| このリポジトリのコード | MIT（`LICENSE`） | |

ピアノ標本は CC BY 3.0 なので**再配布には表示が必要**。画面の脚注と
`public/salamander/CREDITS.txt` に記載してある。取り直すには `npm run fetch:salamander`。

## 作り

- React 19 + Vite 6。外部の音ライブラリは使っていない
- 音は Web Audio API を直に叩く。譜面も賽も鍵盤も Canvas 2D の手描き

| ファイル | 役目 |
| --- | --- |
| `src/progressions.js` | 1787↔1965 のダイヤル、和音、骨の書き出し |
| `src/figuration.js` | 二つの語彙で音型を組む |
| `src/varispeed.js` | 半速で書き出して倍速で戻す |
| `src/engrave.js` | 彫版。調号（嬰・変）、小節ごとの拍子、連桁、装飾記号 |
| `src/perform.js` | 並びを時間の上に置く |
| `src/fortepiano.js` | 音律・合成音・残響の畳み込み |
| `src/salamander.js` | 標本の読み込みと再生 |
| `src/frame.js` | 録画用 1280×720 の組み版 |
